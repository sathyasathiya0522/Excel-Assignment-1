#Excel Assignment 1 – Data Exploration
##Project Overview

This project demonstrates the use of Microsoft Excel for data exploration, analysis, and transformation. Various Excel functions were applied to summarize data, perform logical analysis, conditional aggregation, and text processing.

##Objectives
Analyze product data using Excel formulas.
Perform statistical calculations and data summarization.
Apply logical and conditional functions.
Extract and transform text data using text functions.
Create a well-structured analytical worksheet.
Excel Functions Used
Basic Calculations
SUM() – Calculate the total value.
COUNT() / COUNTA() – Count records.
AVERAGE() – Calculate average values.
Statistical Functions
MIN() – Find the minimum value.
MAX() – Find the maximum value.
Logical Function
IF() – Categorize products based on price conditions.
Conditional Functions
SUMIF() – Calculate total values based on a category.
COUNTIF() – Count records meeting specific criteria.
Text Functions
LEFT() – Extract characters from the left side.
RIGHT() – Extract characters from the right side.
MID() – Extract characters from the middle of a text string.
