# Excel Formulas Assignment

## Overview

This project demonstrates the use of basic Microsoft Excel formulas for data analysis and reporting. The assignment includes mathematical, statistical, logical, and text functions commonly used in Excel.

## Formulas Used

- SUM()
- MIN()
- MAX()
- COUNT()
- AVERAGE()
- AVERAGEIF()
- AVERAGEIFS()
- IF()
- SUMIF()
- COUNTIF()
- RIGHT()
- UPPER()
- LOWER()

## Skills Learned

- Data analysis
- Conditional calculations
- Statistical calculations
- Text formatting
- Business reporting

- Microsoft Excel
